Delfín Check-in social.delfincheckin.com

Publicación social del Mac Mini

Hub OAuth y publicación del pack diario (Reels, carruseles, stories). El Mac Mini genera el contenido; este subdominio recibe el login de TikTok y deja lista la ruta para Instagram, Facebook y YouTube.

Conectar / publicar TikTok Ir al panel admin

Qué hace este dominio

  • Redirect OAuth: https://social.delfincheckin.com/oauth/tiktok
  • Pantalla de publicación: /tiktok (habla con el Mac en local)
  • Mismo proyecto Vercel que admin, tap, clean y g — sin repo nuevo

En el Mac Mini

  • python -m delfin_media day → pack del día
  • python -m delfin_media tiktok serve → API local :8765
  • En .env: TIKTOK_REDIRECT_URI=https://social.delfincheckin.com/oauth/tiktok
