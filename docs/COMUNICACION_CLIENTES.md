# Normas de comunicación con clientes (propietarios)

**Norma de oro:** hacia el propietario **nunca** lenguaje técnico interno. Habla como persona a persona, fácil y rápido — sobre todo en móvil.

## Prohibido decir al cliente

- tenant, SaaS, cron, API, webhook, SMTP, tracking, pixel, UUID  
- onboarding (preferir: *empezar*, *primeros pasos*, *configurar tu alojamiento*)  
- panel / dashboard / backend / deploy  
- “crear cuenta técnica”, “activar tenant”, “magic link”  
- jerga de marketing interno (ICP, funnel, KPI)

## Cómo decirlo

| En vez de… | Di… |
|------------|-----|
| Crear tenant | Probar gratis / Empezar ahora |
| Onboarding | En un minutito estás dentro / Te guiamos paso a paso |
| Magic link | Enlace para entrar (revisa también spam) |
| Plan free + Polar | Gratis sin tarjeta; si te encaja, desde 2€/mes |
| CTA técnico | **Probar gratis ahora** |

## Captación por email (cold)

1. Primero **información útil** (parte de viajeros / RD 933) en lenguaje claro.  
2. Después **un botón** sencillo: *Probar gratis ahora* (sin tarjeta).  
3. En un clic: queda registrado y recibe el correo para entrar (móvil u ordenador).  
4. **Nunca reenviar** al mismo email (norma dura).  
5. Solo **España** y solo **alquiler vacacional / rural / turístico**.

## Objetivo diario

- Meta: **20 altas nuevas / día**.  
- Mañana (~09:00): hasta 50 mails a contactos **nuevos**.  
- Si a las **15:00** aún hay menos de 20 altas → segunda oleada (solo emails **nunca contactados**).  
- A las **11:00** y **19:00**: resumen a Telegram (enviados, abiertos, clicks, altas).
